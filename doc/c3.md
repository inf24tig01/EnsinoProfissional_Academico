## 3.2 Usage

Este projeto é um website informativo e educativo que compara o **ensino profissional** com o **ensino académico** em Portugal. Está organizado em múltiplas páginas HTML que permitem ao utilizador navegar por diferentes conteúdos de forma intuitiva.

### Instruções de Utilização

1. **Abrir o ficheiro `index.html`** num browser (Google Chrome, Firefox, etc.).
2. **Navegar entre páginas** através do menu principal:
   - `index.html` — Página de apresentação.
   - `comparacao.html` — Diferenças e semelhanças entre os tipos de ensino.
   - `percursos.html` — Percursos e saídas profissionais possíveis.
   - `formulario.html` — Quiz interativo para testar conhecimentos.

### Funcionalidades JavaScript

- O projeto inclui **JavaScript** para dinamizar certos elementos da interface:
  - Validação de campos do formulário.
  - Alteração de conteúdos de elementos.
  - Estilização de elementos com base em eventos (ex: clique, hover).
  - Carregamento de ficheiros XML e apresentação dinâmica do conteúdo.

### Limitações

- O projeto não requer autenticação nem registo.
- Todo o conteúdo é estático e não guarda os dados introduzidos no formulário.

### Recursos adicionais

- Ficheiros **XML** e **XSD** validados são utilizados para estruturar e validar conteúdos.
- O código **HTML** e **CSS** está validado com ferramentas da **W3C** (detalhado na secção 3.5).


## 3.3 Application/Product Help

A aplicação é composta por **4 páginas**, sendo todas elas navegáveis através de botões ou menus.

### Interface Gráfica

A interface é simples e organizada, com elementos bem distribuídos por secções.  
Existem **dicas visuais** como:

- **Cores no código HTML e JS** (quando visualizado por programadores);
- **Tooltips** (mensagens de ajuda ao passar o rato sobre os campos);
- **Placeholders** nos inputs, para sugerir o que deve ser preenchido;
- **Atualização dinâmica de valores** (por exemplo, o valor do range é mostrado em tempo real).

A navegação entre páginas é feita por botões ou menus simples e intuitivos.  
A interface é responsiva e adapta-se a diferentes ecrãs.

### XML Validation Description

O ficheiro XML foi validado implicitamente através do carregamento e parsing com JavaScript. Utilizou-se a função `fetch("dados.xml")` para obter o ficheiro, seguida de `DOMParser` para o transformar numa estrutura XML manipulável pelo DOM.

Durante o processamento, os dados foram extraídos de elementos específicos (`<escola>`, `<nome>`, `<localidade>`, `<area>`, `<contacto>`), o que assegura que o ficheiro segue a estrutura esperada. 

Se o XML estiver mal formado ou não contiver os elementos corretos, o JavaScript gera um erro, impedindo a sua utilização. Isto funciona como uma forma básica de validação estrutural.
