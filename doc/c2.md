# C2 : User Interface

### Organização da Informação no Website

O website está dividido em **quatro páginas principais**, acessíveis através do menu:

### Home Page
Apresentação do projeto, objetivos e uma imagem ilustrativa sobre os dois tipos de ensino.

###  Diferenças e Semelhanças
Comparação clara entre o Ensino Profissional e o Ensino Académico.

###  Percursos e Saídas Profissionais
Explicação dos caminhos possíveis após cada tipo de ensino e as suas oportunidades profissionais.

###  Mini Inquérito
Um pequeno questionário para recolher opiniões dos visitantes.
